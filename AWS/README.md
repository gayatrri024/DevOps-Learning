# AWS Learning Projects

This folder contains hands-on AWS and application deployment practice.

## Projects

- **DynamoDB Node.js application:** Node.js application files and Docker configuration.

## Learning objectives

- Understand AWS service integration.
- Practice application configuration and deployment.
- Learn how containerized applications interact with cloud services.

## Safety

Never commit AWS access keys, credentials, `.env` files, or other secrets.
Use IAM roles and least-privilege permissions where applicable.
