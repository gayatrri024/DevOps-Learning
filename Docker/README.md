# Docker Learning Projects

This folder contains containerization practice projects.

## MongoDB Profile App

Location: `02-MongoDB-Profile-App-Docker/`

The project includes a Node.js application, package configuration,
MongoDB-related configuration, and supporting documentation.

## Learning objectives

- Understand Docker images and containers.
- Explore application dependencies and container configuration.
- Practice connecting an application with MongoDB.

## Useful commands

```bash
docker build -t profile-app .
docker images
docker ps -a
```

Run commands from the project directory and review its README
before starting the application.
